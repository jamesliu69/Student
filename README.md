# 115 學年度大學志願校系探索與分析平台

本專案將《115學年度志願校系學習內容未來出路與缺點分析》與《未在清單中（備援補充校系）》兩份升學志願文件完整資料化，整理為一套高度互動、響應式且可免費發佈的單頁網頁系統（Single Page Application）。

---

## 🌟 專案特色

1. **完整 100 個志願校系深度剖析**：
   - 涵蓋「主要學習內容」、「未來可能出路」以及最重要的「**缺點／風險（選系前必看）**」。
   - 標示國立/私立、領域標籤及官方簡章 PDF 順位。

2. **強大多維度過濾與即時搜尋**：
   - **全文綜合搜尋**：支援搜尋校名、系名、關鍵字（例如：`AI`、`半導體`、`無塵室`、`研究所`、`軟體` 等）。
   - **分類篩選**：公私立大學過濾、錄取機率區間過濾（高機率 / 中等 / 衝刺挑戰）、領域快速標籤切換。
   - **多種排序**：預設 PDF 順位、通過機率由高至低 / 由低至高、校系名稱拼音。

3. **志願比對與收藏系統**：
   - **橫向比對 (Compare)**：可選擇 2~4 個校系，進行一對一縱向/橫向優缺點與風險併排比對。
   - **個人收藏 (Bookmarks)**：支援一鍵星星收藏，並將收藏資料持久化儲存於瀏覽器 LocalStorage。

4. **備援校系庫與填報策略**：
   - 整合補充之國立與私立老牌工科/電資校系庫。
   - 提供 1~15 衝刺夢幻、16~50 務實落點、51~100 安全保底之三階段志願填報建議策略與專家提醒。

5. **友善列印與 PDF 匯出**：
   - 內建 Print CSS 樣式，可直接在瀏覽器按下 `Ctrl + P` 或點擊列印按鈕，匯出排版整齊的紙本報告或 PDF 檔。

## 🚀 開啟與使用方式

### 1. 本地直接開啟

本網頁設計為零相依套件（Zero Dependency），無需安裝 Node.js 或執行伺服器。
直接雙擊開啟 `index.html` 即可使用所有功能！

### 2. 免費網站發佈 (Deploy)

#### 方案 A：GitHub Pages (推薦)

1. 將此專案程式碼推送到 GitHub 儲存庫（Repository）。
2. 在 GitHub 儲存庫頁面點擊 **Settings** -> **Pages**。
3. 在 **Source** 選擇 `main` (或 `master`) 分支與 `/ (root)` 資料夾，點擊 **Save**。
4. 約 1 分鐘後即可獲得免費的網址（例如：`https://username.github.io/Student/`）。

#### 方案 B：Vercel / Netlify / Cloudflare Pages

1. 將專案連結至 Vercel 或 Netlify 帳號。
2. Build Command 留空，Publish Directory 設為 `.` 即可完成秒速發佈。
